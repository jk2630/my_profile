Current work in LLM inference & GPU performance.

Two active research directions focused on understanding where modern language-model inference leaves performance on the table — and how to recover it.

Diffusion Language Models · Inference Systems

Optimizing dLLM Inference & Speculative Decoding

Profiling and comparing inference behavior across several approximately 7B-parameter diffusion language models, with an emphasis on identifying kernel- and decoding-level bottlenecks.

  • Ran and profiled LLaDA, DiffuseGemma, SDAR, and Dream on single-prompt inference workloads.
  • Comparing GPU execution traces, kernel behavior, memory activity, and model-specific inference patterns to locate optimization opportunities.
  • Exploring kernel-level optimizations and alternative execution strategies for improving inference efficiency.
  • In parallel, investigating ways to improve speculative decoding for diffusion-style generation.
Current focus: converting profiler findings into concrete kernel and speculative-decoding optimizations, then measuring latency and throughput improvements.

ONGOING
Autoregressive LLMs · GPU Microarchitecture

Finding SM-Level Idle Compute During Llama Prefill

Profiling the prefill phase of a locally running Llama 3 2B-class model to understand why high aggregate GPU utilization can still hide underused CUDA execution resources inside individual SMs.

  • Profiled the prefill workload and began tracing periods where some CUDA cores remain idle despite apparently strong overall utilization.
  • Studying whether those idle periods are caused by memory / I/O stalls, dependency waits, synchronization, or GPU resource constraints.
  • Analyzing SM-level execution behavior across clock cycles to identify compute capacity that is not being productively scheduled.
  • Exploring whether independent useful work can be scheduled into those idle execution slots without interfering with the critical prefill path.
Current focus: characterizing the exact stall sources first, then testing safe ways to overlap or co-schedule work on otherwise idle GPU resources.
